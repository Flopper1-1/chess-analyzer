## Holly's Chess Analyzer v1.10.0-beta.12

### Crash Reporter & Bug Reporting
- **In-App Crash Dialog**: If the application encounters an unhandled error or crashes, a crash dialog will now automatically appear with an option to report the issue directly via the **[Crash Report Form](https://forms.gle/NyNHs2tAn8jYpRP76)**, copy error details / traceback to clipboard, and save the traceback to `%APPDATA%\ChessAnalyzer\crash.log`.
- **Report Issue / Crash from Toolbar**: Clicking "Report an Issue" in the main toolbar now offers quick one-click access to both the **Crash / Bug Report Form** and **GitHub Issues**.
- **GitHub Integration**: Added the Crash & Bug Report Form link to the GitHub README and GitHub issue templates for seamless reporting without requiring a GitHub account.
