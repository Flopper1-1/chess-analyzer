## Holly's Chess Analyzer v1.10.0-beta.2 (Pre-release)

### What's New
- **Annotation Template System**: Added a full template library to **Profile -> Annotations** (`Default [Built-in]` read-only + custom `[Custom]` templates). Create, switch, or delete annotation templates, with per-template icon overrides (editable in Microsoft Paint) and per-template legacy symbols, colours, and style mode (`Icons` / `Legacy`).

### Previous Pre-release Fixes (v1.10.0-beta.1)
- **Automatic Pre-release Updates**: Pre-release builds automatically install newer pre-releases on startup (toggleable in **Settings -> Updates**).
- **Pre-release / Stable Channel Switcher**: Switch between the latest stable release and the latest pre-release on GitHub from **Settings -> Updates**.
- **Annotation System in Settings**: **Annotation system** (`Modern` / `Legacy`) under **Settings -> Analysis**.
- **Light Mode Scroll Areas**: Fixed dark backgrounds inside **Pieces**, **Sounds**, and **Annotations** scroll areas in Light, High Contrast, and Aqua Blue modes.
- **Transparent Fluent Icon & Live `.exe` Icon Updating**.
- **Automatic Event Switching & Restore**, **Green & White Christmas Board**, and **High Contrast Colour Picker**.
